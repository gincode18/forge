# Forge dashboard

The local Next.js dashboard for Forge, built with TypeScript, Tailwind CSS, and
Shadcn UI.

## Development

This package uses pnpm. From this directory, run:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.

## Checks

```bash
pnpm lint
pnpm build
```

The FastAPI runtime lives in the sibling `../backend` directory.
